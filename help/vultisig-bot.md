# Vultisig Bot

**Bot**: [@VultisigBot](https://t.me/VultisigBot)

{% hint style="warning" %}
The Telegram bot was used to register vaults for the Season 0 $VULT airdrop. $VULT launched on 27 October 2025. Do not treat `/register` as a current airdrop path. Current utility: [in-app fee discounts](../vultisig-token/vult/in-app-utility.md).
{% endhint %}

The bot can still be used to look up a previously registered vault if the bot responds. It does not hold keys, vault shares, or signing authority.
