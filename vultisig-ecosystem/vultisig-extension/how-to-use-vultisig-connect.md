# How to use Vultisig Extension

## How to install Vultisig Extension

Install the Vultisig Extension from the [Chrome Web Store](https://chromewebstore.google.com/detail/vulticonnect/ggafhcdaplkhmmnlbfjpnnkepdfjaelb) (Chrome, Brave, Edge), [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/vultisig-extension/), or from [GitHub](https://github.com/vultisig/vultisig-windows).
