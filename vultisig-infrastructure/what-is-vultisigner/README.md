# Vultiserver

Vultiserver holds one share of a Fast Vault and co-signs with your device. That is a 2-of-2: your device plus the server. You get one-device signing. The complete key is never assembled.

{% hint style="info" %}
Configurable spending limits, address allowlists, and time delays are [not in the apps](what-can-be-configured.md). Fast Vault today is password + server auto-cosign after you approve the transaction on your device.
{% endhint %}

See [How a Fast Vault works](how-does-vultisigner-work.md) and [Why Vultiserver is safe](why-is-it-safe.md).
